# MedHear – Indian Sign Language Medical Communication Assistant

MedHear is an assistive communication prototype that helps deaf patients communicate common medical symptoms and needs to healthcare professionals. It recognizes a small, fixed vocabulary of Indian Sign Language (ISL) medical signs via webcam and converts them into a structured text report.

## What this is
- Recognition of a limited, predefined set of ISL signs (body parts, symptoms, healthcare terms) — not full sign-language translation.
- A patient-facing sign detection flow that builds a report from recognized signs.
- A healthcare-professional dashboard to review, edit, and confirm AI-detected signs.

## What this is NOT
- Not a diagnostic tool. It does not diagnose conditions or recommend medication.
- Not a full ISL-to-English translator or continuous/sentence-level sign recognition system.
- Not a replacement for a doctor or professional interpreter.

## Tech stack
- Frontend: Next.js, React, Tailwind CSS
- Backend: FastAPI (Python)
- AI/CV: MediaPipe, OpenCV, TensorFlow/PyTorch
- Database: MongoDB
